# ҰБТ Дайындық — платформа подготовки к ҰБТ

Фронтенд образовательной платформы для подготовки к ҰБТ на казахском языке.
Стек: **Next.js 14 (App Router) + React 18 + TypeScript + Tailwind CSS**.

> На данном этапе данные — мок (`lib/mock-data.ts`). Бэкенд (NestJS + PostgreSQL),
> JWT-авторизация и Kaspi API подключаются позже на месте заглушек.

## Запуск

Требуется **Node.js 18.18+** (рекомендуется LTS). Скачать: https://nodejs.org

```bash
npm install      # установить зависимости (один раз)
npm run dev      # запустить dev-сервер
```

Открыть в браузере: http://localhost:3000

Прочие команды:

```bash
npm run build    # production-сборка
npm run start    # запуск собранного приложения
```

## Структура

```
app/
├── page.tsx              Главная (Hero, статистика, преимущества, тарифы, CTA)
├── login/               Вход
├── register/            Регистрация
├── forgot-password/     Восстановление пароля
├── dashboard/           Личный кабинет (метрики, график, история, достижения)
├── tests/               Список тестов с фильтрами
│   └── [id]/            Прохождение теста (таймер, проверка, разбор)
├── trial/               Пробное ҰБТ (симуляция экзамена)
├── rating/              Рейтинг учеников
├── pricing/             Тарифы + оплата Kaspi (демо-модалка)
└── achievements/        Достижения
components/              Header, Footer, AuthShell, TestRunner, ProgressChart
lib/mock-data.ts         Демо-данные (предметы, тесты, вопросы, рейтинг и т.д.)
```
